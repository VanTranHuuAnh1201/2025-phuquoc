## 1. Bối cảnh

Trang `/lookup` đang gọi `GET /api/bookings?code=&phone=` — route bọc
`withAuthGuard` nên khách chưa đăng nhập nhận **401**. Ticket này đổi sang route
công khai `390-03` đã tạo.

## 2. Phạm vi

**Trong:** trang `/lookup` gọi API mới · xử lý 400/404/429 bằng chữ · trạng thái rỗng.

**Ngoài:** viết API → `390-03` [BE].

## 3. Dữ liệu vào / ra

```
apps/2026-thenamduhill/src/app/lookup/page.tsx   đổi endpoint sang /api/bookings/lookup
```

## 5. Tiêu chí chấp nhận (AC)

| # | AC | Kiểm bằng |
|:--:|---|---|
| 1 | Trang `/lookup` gọi `/api/bookings/lookup`, **không** gọi `/api/bookings` | `grep` + Network tab |
| 2 | **Khách chưa đăng nhập tra được** — không còn 401 | Mở ẩn danh, tra thử |
| 3 | Tra đúng → hiện đơn với mã, hạng phòng, ngày nhận/trả, trạng thái, tổng tiền, số dư | Tra thử |
| 4 | **Badge trạng thái có chữ**, không chỉ màu (luật D4) | Xem UI |
| 5 | **Negative 404**: sai mã hoặc sai SĐT → *"Không tìm thấy đơn khớp mã và số điện thoại đã nhập. Kiểm tra lại giúp bạn."* — **không** nói rõ cái nào sai | 2 case |
| 6 | **Negative 400**: thiếu một trong hai ô → lỗi cạnh đúng ô, `aria-live="polite"` | 2 case |
| 7 | **Negative 429**: tra quá nhiều → *"Bạn đã tra cứu quá nhiều lần. Thử lại sau ít phút."* | 1 case |
| 8 | Trạng thái rỗng ban đầu nói rõ phải làm gì (luật FE7) | Mở trang |
| 9 | Đủ **7 trạng thái UI** (luật FE1); `loading` giữ nguyên kích thước nút | Kiểm |
| 10 | `autoComplete="tel"` + `inputMode="tel"` cho ô SĐT — trên điện thoại hiện bàn phím số | Điện thoại thật |
| 11 | Song ngữ toàn bộ kể cả lỗi và `aria-label` | Đổi locale |
| 12 | Mobile 375px: target ≥ 44px, không cuộn ngang | Mở 375px |
| 13 | **Không hiện dữ liệu nhạy cảm** khách không cần thấy (CCCD, ghi chú nội bộ) — kể cả khi API lỡ trả | Xem DOM |
| 14 | **Cập nhật MAP**: cột FE của M11 → ✅ | Đọc MAP |
| 15 | `pnpm test` xanh, lint/typecheck sạch, `build:safe` xanh 4 theme | Chạy lệnh |
