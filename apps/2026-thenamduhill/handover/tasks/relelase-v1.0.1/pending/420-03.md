## 1. Bối cảnh

Outbox có rồi, worker có rồi — nhưng nếu không có màn hình thì khi một event
`failed` **không ai biết**. Với đồng bộ phòng lên OTA, một event mất nghĩa là
Booking.com vẫn mở bán phòng đã bán.

Đây là màn hình chị (hoặc quản lý) mở khi nghi ngờ *"lịch trên Airbnb sao chưa
khoá"*.

## 2. Phạm vi

**Trong:** màn `/admin/settings/integrations` — bảng outbox theo format §F6, nút
thử lại, bật/tắt adapter, chỉ báo sức khoẻ.

**Ngoài:** sửa payload event (không cho sửa — outbox là bản ghi sự kiện).

## 3. Dữ liệu vào / ra

```
apps/2026-thenamduhill/src/app/admin/settings/integrations/page.tsx   MỚI
apps/2026-thenamduhill/src/app/api/admin/outbox/route.ts              MỚI (GET danh sách)
apps/2026-thenamduhill/src/app/api/admin/outbox/[id]/retry/route.ts   MỚI (POST thử lại)
```

Route mới phải có `requirePermission` — chỉ `owner`/`manager` (lễ tân không cần
thấy màn này).

## 5. Tiêu chí chấp nhận (AC)

| # | AC | Kiểm bằng |
|:--:|---|---|
| 1 | Bảng theo **đủ format §F6**: tiêu đề + đếm, ô tìm, bộ lọc + nút Đặt lại, chọn nhiều, header in hoa `scope="col"`, phân trang "Hiển thị x–y trong z" | Đối chiếu từng dòng §F6 |
| 2 | **Badge trạng thái có CHỮ**, không chỉ màu (luật D4) | Xem 4 trạng thái |
| 3 | Số liệu canh phải, `tabular-nums` | Đọc CSS |
| 4 | Nút "Thử lại" **chỉ hiện** ở dòng `failed`/`dead` | Đối chiếu |
| 5 | Bấm "Thử lại" → event về `pending`, `next_retry_at = now()` | Bấm, xem DB |
| 6 | **Không cho sửa `payload`** — outbox là bản ghi sự kiện, chỉ đọc | Không có nút Sửa |
| 7 | Xem chi tiết → hiện `payload` đầy đủ + `last_error` **nguyên văn** | Bấm 👁 |
| 8 | **Trạng thái rỗng nói rõ phải làm gì** (luật FE7): *"Chưa có event nào trong 7 ngày qua. Đổi bộ lọc để xem thêm."* — không phải "Không có dữ liệu" | Lọc ra rỗng |
| 9 | Đủ **7 trạng thái UI** cho mọi phần tử tương tác (luật FE1) | Kiểm từng nút |
| 10 | Mobile 375px: **đổi sang thẻ, không cuộn ngang**; mọi target ≥ 24px, CTA ≥ 44px | Mở 375px |
| 11 | Song ngữ toàn bộ, kể cả trạng thái rỗng và `aria-label` (luật FE6) | Đổi locale |
| 12 | Icon SVG (`lucide-react`), **không emoji** (luật FE9) | Đọc code |
| 13 | **Negative**: lễ tân đăng nhập → **không thấy** menu Tích hợp, gọi API trực tiếp trả **403** | 2 case |
| 14 | **Negative**: bấm "Thử lại" khi event đã `sent` → **422**, kèm thông báo bằng chữ | 1 case |
| 15 | 0 hex ngoài `tokens.css`, dùng token cho mọi màu/spacing | `grep` hex |
| 16 | `pnpm test` xanh, lint/typecheck sạch, `build:safe` xanh 4 theme | Chạy lệnh |
