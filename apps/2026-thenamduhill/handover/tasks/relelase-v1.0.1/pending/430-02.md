**Mobile**: ô kéo-thả đổi thành nút "Chọn ảnh" mở thẳng thư viện điện thoại — kéo
thả không dùng được trên cảm ứng. Đây là thiết kế riêng cho mobile, không phải
`flex-direction: column` (luật FE5/P9).

## 5. Tiêu chí chấp nhận (AC)

| # | AC | Kiểm bằng |
|:--:|---|---|
| 1 | Kéo-thả **nhiều ảnh cùng lúc**, mỗi ảnh có thanh tiến trình riêng | Kéo 5 ảnh |
| 2 | Sắp xếp lại thứ tự bằng kéo — **và bằng bàn phím** (luật FE11: điều hướng bàn phím đầy đủ) | Tab + mũi tên |
| 3 | Ảnh đầu tiên là ảnh đại diện, **nói rõ bằng chữ** trên UI | Xem UI |
| 4 | Xoá một ảnh không làm mất ảnh đang tải khác | Xoá giữa lúc đang tải |
| 5 | Dùng `srcset` từ `430-01` — thẻ `<img>`/`next/image` có `srcSet` + `sizes` | Xem DOM |
| 6 | `blurDataURL` làm placeholder khi đang tải | Xem DOM |
| 7 | **Alt song ngữ bắt buộc** VI + EN cho mỗi ảnh (luật C7/D4) | Thiếu alt → cảnh báo |
| 8 | Đủ **7 trạng thái UI** (luật FE1). `loading` **giữ nguyên kích thước** để không nhảy layout | Kiểm từng trạng thái |
| 9 | **Negative**: file quá 15MB → thông báo **bằng chữ** *"Ảnh vượt 15MB. Chọn ảnh nhỏ hơn."*, các ảnh khác vẫn tải | 1 case |
| 10 | **Negative**: mất mạng giữa lúc tải → hiện lỗi + nút **Thử lại** cho đúng ảnh đó, không mất ảnh đã xong | 1 case |
| 11 | **Negative**: chọn file PDF → loại ngay ở client kèm lý do, không gửi lên server | 1 case |
| 12 | **Mobile 375px**: nút "Chọn ảnh" mở thư viện điện thoại; target ≥ 44px; **không cuộn ngang** | Mở 375px |
| 13 | Song ngữ toàn bộ kể cả `aria-label` và thông báo lỗi | Đổi locale |
| 14 | Icon SVG (`lucide-react`), không emoji (luật FE9) | Đọc code |
| 15 | 0 hex ngoài `tokens.css`; radius/spacing lấy từ token | `grep` hex + px thô |
| 16 | **Tải ảnh 8MB từ điện thoại thật → xong dưới 10 giây**, có tiến trình suốt quá trình | Đo thật trên điện thoại, ghi số |
| 17 | `pnpm test` xanh, lint/typecheck sạch, `build:safe` xanh 4 theme | Chạy lệnh |
